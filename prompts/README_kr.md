# Prompts

이 디렉터리의 기준 문서는 영어이며, 한국어 보조 문서는 `_kr.md` suffix를 사용한다. 영어 기준 문서는 [README.md](README.md)에서 볼 수 있다.

## 목적
이 디렉터리는 분포 변화 하에서의 추론 행동을 살피기 위해 사용하는 기준 프롬프트 세트를 담고 있다.

## 사용 가능한 프롬프트 세트
- [`paris_id_ood.md`](paris_id_ood.md): 현재 Paris 도메인 연구에 쓰인 영어 프롬프트 쌍
- [`paris_id_ood_kr.md`](paris_id_ood_kr.md): 같은 프롬프트 쌍의 한국어 보조 문서

## 설계 메모
- ID 프롬프트는 비교적 단순한 benchmark 스타일 문구를 사용한다.
- OOD 프롬프트는 관점 전환, 형식 제한, 금지 단어 같은 현실적인 사용자 제약을 도입한다.
- 현재 저장소는 하나의 도메인에 집중해 프롬프트 프레이밍, 반복 실행, 실패 라벨을 쉽게 비교할 수 있게 구성했다.
