# 분포 변화 하에서의 대규모 언어 모델 추론 실패 양상 및 불확실성 분석

## 연구 동기 (Motivation)
대규모 언어 모델(Large Language Models, LLMs)은 표준 벤치마크 환경에서는 우수한 성능을 보인다. 그러나 실제 환경에 배포될 경우,
입력 분포의 변화(distribution shift), 모호한 지시문, 계산 자원 제약 등의 요인으로 인해 추론 과정에서 신뢰성이 급격히 저하되는 문제가 빈번히 발생한다.

본 연구는 새로운 모델 구조를 제안하거나 벤치마크 정확도를 향상시키는 데 초점을 두기보다는, 실제 환경에서 LLM이 추론 과정 중 *어떤* 방식으로 실패하며 *왜* 이러한 실패가 발생하는지를 체계적으로 이해하는 것을 목표로 한다.

## 연구 질문 (Research Question)
본 프로젝트는 다음과 같은 연구 질문에 답하고자 한다.

- 입력 분포 변화 하에서 LLM의 실패 양상(failure mode)은 어떻게 달라지는가?
- 추론 시 디코딩 전략(예: greedy 디코딩과 sampling 기반 디코딩)은 모델의 신뢰성과 실패 특성에 어떤 영향을 미치는가?
- 출력 다양성(output variability)과 같은 단순한 지표를 통해 과도하게 확신적인(overconfident) 혹은 신뢰하기 어려운 생성 결과를 식별할 수 있는가?

## 연구 방법 (Approach)
본 연구는 기존의 대규모 언어 모델을 대상으로 학습(training)이 아닌 추론(inference) 단계의 행동을 분석하는 데 초점을 둔다.
구체적으로 다음과 같은 방법을 사용한다.

- In-distribution(ID) 및 Out-of-distribution(OOD) 프롬프트를 의도적으로 설계
- 결정론적(greedy) 디코딩과 확률적(sampling 기반) 디코딩 전략 비교
- 환각(hallucination), 지시 오해(instruction misunderstanding), 부분적 정답(partial correctness), 과도한 확신(overconfidence) 등 대표적인 실패 양상에 대한 분류 체계 수립
- 동일 입력에 대한 출력 변동성을 불확실성(uncertainty)의 대리 지표(proxy)로 활용하여 정성적·정량적 분석 수행

본 프로젝트는 모델 학습이나 성능 경쟁보다는, 추론 신뢰성 분석과 평가 방법론에 중점을 둔다.
