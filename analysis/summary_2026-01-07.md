# Summary (2026-01-07)

## Scope
This summary covers initial inference-behavior experiments on a familiar domain (Paris),
comparing an ID baseline prompt against an OOD prompt with an explicit constraint.

## Experiments
### ID (baseline)
- Prompt: "Describe the city of Paris in two sentences."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)

### OOD (constraint: no landmarks)
- Prompt: "Describe the city of Paris in two sentences without mentioning any famous landmarks."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Rule: If the model requests a preference between multiple responses, do not choose; record and end the run.

## Key Observations
- **ID baseline** generations were coherent and low-variance, with repeated motifs (e.g., iconic landmarks, culture, cafés, the Seine) and no notable failure modes.
- **OOD no-landmarks** generations generally adhered to the constraint (no landmark mentions) and shifted toward everyday-life framing (cafés, markets, neighborhoods, conversation, “human-paced” rhythm).
- In the OOD setting, the model occasionally produced multiple candidate responses and asked the user to choose (`needs-user-choice`), adding interaction cost despite otherwise strong constraint adherence.

## Takeaway
A simple OOD constraint can meaningfully change the style and content framing of outputs while remaining mostly enforceable. However, even when constraints are followed, the model may intermittently avoid committing to a single completion (choice request), which complicates deterministic evaluation and suggests residual instability under constrained prompting.

## Next Steps
- Add additional OOD constraint types (e.g., strict format constraints, forbidden-word constraints) and compare failure-mode frequencies across constraint classes.
- Run the same prompt sets on a second model to test whether `needs-user-choice` behavior is model-specific.
