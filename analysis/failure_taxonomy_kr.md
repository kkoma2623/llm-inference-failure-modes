# Failure Taxonomy (v0.1)

이 파일의 기준 문서는 영어이며, 영어 원문은 [failure_taxonomy.md](failure_taxonomy.md)에서 볼 수 있다.

이 문서는 실험 노트에서 사용하는 기본 실패 양상 라벨을 정의한다. 한 run에 여러 문제가 있어도 기본 라벨은 하나만 부여한다.

## 라벨

### ok
출력이 프롬프트와 제약을 눈에 띄는 문제 없이 따른 경우다.

### instruction violation
금지 단어, 요구 형식, 길이 제한, 문장 수 제한 같은 명시적 제약을 지키지 못한 경우다.

**예시**
- 금지된 단어나 랜드마크를 언급함
- 요구된 문장 수를 초과함
- bullet 또는 문단 형식을 지키지 않음

### hallucination
근거 없는 세부사항을 사실처럼 제시한 경우다.

**예시**
- 뒷받침 없이 특정 사건, 통계, 위치 정보를 단정함
- 프롬프트가 암시하지 않은 구체 정보를 만들어 냄

### partial correctness
출력은 주제와 관련이 있지만 불완전하거나, 과도한 포맷팅이 있거나, 요청을 약하게만 만족하는 경우다.

**예시**
- 금지 단어는 피했지만 지나치게 모호해짐
- 핵심 프레이밍을 놓침
- 텍스트 전용 평가인데 요청되지 않은 이미지 블록을 덧붙임

### overconfidence
틀렸거나 근거가 약한 내용을 지나치게 확신하는 어조로 제시한 경우다.

**예시**
- 불확실한 주장에 강한 확신 표현을 사용함
- 검증하기 어려운 세부사항을 단정적으로 말함

### needs-user-choice
하나의 최종 답을 내지 않고 여러 후보를 제시한 뒤 사용자의 선택을 요구하는 경우다.

**예시**
- "Response 1 ... Response 2 ... Which do you prefer?"
- "Pick one of these options ..."

## 메모
- 여러 문제가 함께 보이면 가장 중심적인 문제를 기본 라벨로 선택한다.
- 부수적인 문제는 `notes.md`의 Quick Observations 섹션에 적는다.
