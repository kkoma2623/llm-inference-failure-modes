# Summary (2026-01-09) — Prompt Set 5

## Scope
This summary covers experiments comparing an ID travel-description prompt against an OOD prompt that forbids specific words (“France”, “city”, “capital”). Text-only evaluation was used; media may be omitted.

## Experiments
### ID (baseline)
- Prompt: "Describe Paris as a travel destination."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

### OOD (constraint: forbidden words)
- Prompt: "Describe Paris as a travel destination without using the words “France”, “city”, or “capital.”"
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

## Key Observations
- **ID baseline** outputs were coherent and template-like, repeatedly covering attractions, culture, food/café culture, neighborhoods, walkability/transport, and atmosphere.
- **OOD forbidden-words** outputs showed strong compliance: all runs avoided the banned words while maintaining fluency and readability.
- The primary adaptation was lexical substitution (e.g., “destination/place/areas”) with minimal change in content selection (landmarks/neighborhoods remained present).

## Takeaway
This forbidden-words constraint appears “easy”: it mainly changes wording rather than shifting underlying content, suggesting high robustness for shallow lexical constraints under text-only evaluation.

## Next Steps
- Increase constraint difficulty (longer banned list, or “no landmark names”) to probe when compliance begins trading off with informativeness and naturalness.
