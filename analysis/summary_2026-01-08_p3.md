# Summary (2026-01-08) — Prompt Set 3

## Scope
This summary covers experiments comparing an ID “known-for” prompt against an OOD prompt with a strict output-format constraint (exactly three bullet points, each under ten words). Image links were ignored and only text was evaluated.

## Experiments
### ID (baseline)
- Prompt: "What is Paris known for?"
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

### OOD (format constraint)
- Prompt: "What is Paris known for? Answer using exactly three bullet points, each under ten words."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

## Key Observations
- **ID baseline** outputs were stable and category-driven (landmarks, art/museums, fashion, cuisine/café culture, romance/atmosphere, Seine), with minor stylistic differences and occasional optional “tailoring offer” add-ons.
- **OOD format-constraint** outputs showed strong compliance (3 bullets, <10 words) and became near-deterministic across runs (some runs identical), indicating reduced output variability under strict formatting.
- The strict format constraint compressed content into a small set of stereotyped attributes, suggesting a trade-off: higher formatting reliability but reduced richness/coverage.

## Takeaway
A strict formatting constraint substantially increases determinism and compliance, but it also encourages generic compression into a default attribute set. This highlights a reliability–expressiveness trade-off under OOD format constraints in text-only evaluation.

## Next Steps
- Test additional format variants (e.g., “exactly 2 bullets”, “no emojis”, “one sentence”) to map how constraint type affects determinism vs content diversity.
- Compare ID vs OOD outputs using simple metrics (e.g., unique n-grams or repeated motifs) to quantify variability reduction under format constraints.
