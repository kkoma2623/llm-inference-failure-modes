## 측정 메모
- 기본 라벨은 각 실험의 `notes.md`에서 직접 집계했다.
- 동일 출력 군집은 이미지 링크와 run 구분선을 제거한 텍스트 본문 기준으로 계산했다.
- 평가 프로토콜이 미디어를 무시하므로, 중복 수치는 텍스트 답변 본문에만 초점을 맞춘다.

## 해석
- 큰 동일 출력 군집이 나타난 유일한 조건은 P3 OOD이며, 이는 엄격한 형식 제약이 결정성을 높인다는 해석을 뒷받침한다.
- P2는 ID와 OOD 모두에서 체계적으로 non-ok 라벨이 나온 유일한 프롬프트 계열이며, 문제의 핵심은 주제 이탈이 아니라 과도한 포맷팅이다.
- OOD 행동은 전반적으로 강건했다. OOD `30`회 중 `24`회가 `ok`였고, 나머지 `6`회는 선택 요청 1회와 이미지가 붙은 관광 요약 5회로 설명된다.
