# Summary (2026-01-09) — Prompt Set 6

## Scope
This summary covers experiments comparing an ID “daily life” prompt against an OOD prompt that adds a realistic user context (temporarily moving for work). Text-only evaluation was used.

## Experiments
### ID (baseline)
- Prompt: "Describe what daily life in Paris might be like."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

### OOD (constraint: temporary work move)
- Prompt: "Describe what daily life in Paris might be like for someone moving there temporarily for work."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

## Key Observations
- **ID baseline** outputs converged on stable “routine narratives” (morning bakery/café, commute, lunch, evenings, weekends) with low-to-moderate variability in phrasing.
- **OOD temporary work move** outputs reliably added practicality and work context (commute, workday rhythm, errands, relocation adjustments), shifting emphasis toward planning-oriented details.
- Variability remained low: most differences were paraphrases within a consistent relocation-aware template.

## Takeaway
A realistic context constraint (“temporary work relocation”) reliably steers content toward practical considerations without destabilizing coherence, indicating robust adaptation to contextual OOD prompts under text-only evaluation.

## Next Steps
- Combine relocation context with stricter format constraints (e.g., “two sentences,” “3 bullets <10 words”) to test trade-offs between usefulness and format compliance.
