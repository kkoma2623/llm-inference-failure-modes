# Summary (2026-01-08) — Prompt Set 2

## Scope
This summary covers inference-behavior experiments on a familiar domain (Paris), comparing an ID prompt against an OOD prompt that adds a user-specific preference constraint (crowd aversion). Image links were ignored and only text was evaluated.

## Experiments
### ID (baseline)
- Prompt: "Summarize Paris as a tourist destination."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

### OOD (constraint: dislikes crowds)
- Prompt: "Summarize Paris as a tourist destination for someone who dislikes crowded places."
- Runs: 5 (identical prompt repeated consecutively in a fresh chat)
- Evaluation: Text-only (ignore image links/media)

## Key Observations
- **ID baseline** outputs were coherent and largely template-like, repeatedly emphasizing landmarks, museums/art, cuisine/café culture, walkability/public transit, and day trips.
- **OOD dislikes-crowds** outputs reliably shifted framing toward crowd-avoidance strategies (off-peak timing, quieter neighborhoods/parks, “atmosphere over attractions”), while still presenting Paris as a compelling destination.
- Across both conditions, outputs showed low-to-moderate variability with consistent structural patterns; the main difference was the OOD prompt’s stronger emphasis on timing and quiet-area recommendations.

## Takeaway
Adding a realistic user constraint (“dislikes crowded places”) reliably steers content selection and recommendations without breaking coherence. Compared to the ID baseline, the OOD prompt induces a more tailored planning-oriented summary, indicating robust constraint-sensitive adaptation in text-only evaluation.

## Next Steps
- Introduce stricter OOD constraints (format/forbidden words) on the same tourism prompt and compare failure-mode frequency across constraint classes.
- Run the same ID/OOD pair on a second model to see whether the crowd-averse tailoring pattern generalizes.
